Афиша для йога-тура

Соберите постер для ретрита в Сочи или Абхазии: место, формат и настроение задают фон через Pollinations Image API, а название и даты аккуратно накладываются поверх в браузере.

Место

Ключ никуда не отправляется, кроме официального API gen.pollinations.ai, и не записывается в репозиторий. Без ключа сработает только ответ из общего кэша. Для постоянной работы посетитель тратит свой Pollen. Не вставляйте секретный ключ аккаунта в публичную страницу как значение по умолчанию.

Здесь появится афиша
Свободный статический инструмент. Фон генерирует Pollinations, текст рисуется локально, чтобы кириллица оставалась ровной. Не содержит секретных ключей.
